# RiZe Landing Page

## Project Overview

RiZe is an upcoming iOS app built with creator Maxwell Rhoe for his Gen-Z audience.

**Concept:** You define who you're becoming, then prove it with one meaningful action every day — a Daily Proof. The community does proofs together.

**Tagline:** "Create your Next Self. Prove it every day."

## What This Repo Is

This is NOT the app. This is the pre-launch waitlist landing page.

**Single purpose:** Maxwell's followers land here from his bio links and drop their email. We're using signups to validate demand before building the app.

## Key Considerations

- Traffic is almost all mobile — design and test mobile-first
- Audience is Gen-Z via Maxwell's social following
- Conversion is everything: email capture is the only metric that matters
